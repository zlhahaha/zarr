These twenty-eight tiny Zarr stores were generated by `scripts/generate_interop_fixtures.py`, `scripts/generate_compressed_fixtures.py`, `scripts/generate_zstd_fixtures.py`, `scripts/generate_u16_fixtures.py`, `scripts/generate_i16_fixtures.py`, `scripts/generate_u32_fixtures.py`, `scripts/generate_i64_fixtures.py`, `scripts/generate_i8_fixtures.py`, `scripts/generate_group_fixtures.py`, `scripts/generate_consolidated_fixture.py`, `scripts/generate_v3_consolidated_fixture.py`, `scripts/generate_bool_fixtures.py`, and `scripts/generate_nonfinite_fixtures.py` using zarr-python 3.4.0 and NumPy 2.5.3. The scripts and test values were written for this project; no upstream source code or test fixture was copied. zarr-python itself is MIT-licensed: <https://github.com/zarr-developers/zarr-python/blob/main/LICENSE>.

To regenerate, first move or remove only the named `*.zarr` fixture directories above, then run the relevant generator with zarr-python 3.4.0. The native MoonBit tests open these stores directly. The reverse-direction verifier reads `integration/.roundtrip/`, which is generated by `cmd/interop` and excluded from Git.
