# zarr-python interoperability stores

These five tiny Zarr stores were generated by `scripts/generate_interop_fixtures.py` using zarr-python 3.4.0 and NumPy 2.5.3. The script and numerical test values were written for this project; no upstream source code or test fixture was copied. zarr-python itself is MIT-licensed: <https://github.com/zarr-developers/zarr-python/blob/main/LICENSE>.

| Store | Format | Dtype | Values tested |
| --- | --- | --- | --- |
| `v2_u8.zarr` | v2 | uint8 | 3×4 image, fill 5, values 7 and 9 |
| `v3_u8.zarr` | v3 | uint8 | same image, default chunk keys |
| `v2_f64_be.zarr` | v2 | big-endian float64 | fill 1.5, edge value 42.25 |
| `v3_f32_le.zarr` | v3 | little-endian float32 | fill 1.5, edge value 42.25 |
| `v3_i32_be.zarr` | v3 | big-endian int32 | fill −1, edge value −200 |

To regenerate, first move or remove only the five named `*.zarr` fixture directories above, then run the generator with zarr-python 3.4.0. The native MoonBit tests open these stores directly. The reverse-direction verifier reads `integration/.roundtrip/`, which is generated by `cmd/interop` and excluded from Git.
